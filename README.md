# Reference Guided Sites

Eu te mandei um arquivo JSON com 70 linhas, ele é basicamente a ideia que eu quero fazer no site. Já o segundo arquivo que eu te mandei, é basicamente a estrutura que eu vou querer pra adaptar de acordo com o que eu pedi ali no primeiro prompt. Então eu queria que você olhasse bem, se dedicasse bem a fazer esse site de acordo com a estrutura que eu te mandei. Investir em animações e tudo que eu já pedi. Pode fazer uma análise bem completa do arquivo JSON.

Pois a estrutura que eu te mandei é basicamente só a referência estrutural.
